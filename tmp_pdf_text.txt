Научиться строить серверную часть на PHP 8 без фреймворка по схеме MVC: автозагрузка классов

Краткая теория
•
HTTP-запрос
 — метод (GET читает, POST изменяет), путь (
/employees/2
), строка запроса 
(

), заголовки и тело. 
Ответ
 — код состояния (200, 302, 404, 405, 500), заголовки и 
тело. В PHP метод и адрес лежат в 
$_SERVER['REQUEST_METHOD']
 и 
$_SERVER['REQUEST_URI']
, параметры — в 
$_GET
 и 
$_POST
.
•
Front controller
 — все запросы идут в один файл 
public/index.php
. Он подключает 
автозагрузку, описывает таблицу маршрутов и передаёт запрос нужному контроллеру. 
Папка 
public/
 — единственная видимая из браузера (DocumentRoot); 
src/
, 
views/
, 
config/
 снаружи недоступны.
•
Маршрутизация
 — сопоставление «метод + шаблон пути» с методом контроллера. 
Шаблон 
/employees/{id}
 превращается в регулярное выражение 
#^/employees/(?
P<id>\d+)$#
. В проекте нет адресов вида

.
•
Composer
 — менеджер зависимостей PHP. В нашем проекте он нужен для двух вещей: 
автозагрузка PSR-4 (сейчас) и PHPUnit (лаб. 15). 
PSR-4
: класс 
App\Core\Router
 лежит в 
файле 
src/Core/Router.php
, пространство имён совпадает с папками, имя класса — с 
именем файла (с учётом регистра!).

private function toRegex(string $path): string

    $pattern = preg_replace('#\{(\w+)\}#', '(?P<$1>\d+)', $path);

Главный метод

public function dispatch(string $method, string $uri): void
{
    $path = $this->normalizePath($uri);
    $allowedMethods = [];
    foreach ($this->routes as $route) {
        if (!preg_match($route['regex'], $path, $matches)) {
            continue;
        }
        if ($route['method'] !== $method) {
            $allowedMethods[] = $route['method'];
            continue;
        }
        // Оставляем только именованные параметры: ['id' => '15'] → [15]
        $params = array_filter($matches, 'is_string', ARRAY_FILTER_USE_KEY);
        $params = array_map('intval', array_values($params));
        [$class, $action] = $route['handler'];
        (new $class())->$action(...$params);
        return;
    }
    if ($allowedMethods !== []) {
        http_response_code(405);
        header('Allow: ' . implode(', ', array_unique($allowedMethods)));
        echo '405 Method Not Allowed';

Внутри шаблона

, поэтому доступны помощники. 
render()
 сначала 
рисует страницу, потом вставляет её в макет как переменную

public function render(string $template, array $data = [], ?string $layout = 
'layout'): string
{
    $content = $this->renderFile($template, $data);
    if ($layout === null) {
        return $content;
    }
    return $this->renderFile($layout, $data + ['content' => $content]);
}
private function renderFile(string $template, array $data): string
{
    $file = $this->viewsPath . '/' . $template . '.php';
    if (!is_file($file)) {
        throw new RuntimeException("Шаблон не найден: {$template}");
    }
    // extract() превращает ['employees' => [...]] в переменную $employees
    extract($data, EXTR_SKIP);
    ob_start();
    require $file;
    return (string) ob_get_clean();
}
/** Экранирование для вывода в HTML — защита от XSS. Используйте при КАЖДОМ 
выводе данных. */
public function e(mixed $value): string
{
    return htmlspecialchars((string) $value, ENT_QUOTES | ENT_SUBSTITUTE, 
'UTF-8');
}
